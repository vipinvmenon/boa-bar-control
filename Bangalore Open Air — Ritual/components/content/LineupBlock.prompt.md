**LineupBlock** — the festival bill. Headliners render large in gold, specials in green, supports in bone-white.

```jsx
<LineupBlock columns={2} artists={[
  { name: 'Kryptos', tier: 'headliner' },
  { name: 'Gutslit', tier: 'special' },
  { name: 'Bevar Sea', tier: 'support' },
  { name: 'Dying Embrace', tier: 'support' },
]} />
```

Preserve real band logo lockups where you have them — pass names only when you don't.
